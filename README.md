# wilton

为撰写技术博客设计的终端风格的静态站点生成器

访问量统计和评论区服务目前用的是腾讯的 EdgeOne, 后期会考虑加入更多平台的支持

目前 "Make it work" 阶段应该已经完成了, 开始慢慢对代码进行重构

>

## 构建流程

目前的构建流程是这样的:

1. 初始化数据库与模型
2. 解析用户输入
3. 扫描博客文件夹 一边扫描一边构建数据库
4. 读取配置文件
5. 导入(依赖配置但)与博客内容无关的资产
    1. css/js/fonts 主题文件和 attachments 目录
    2. 图标
    3. 云函数
6. 编译文章与页面
7. 根据数据库生成构建产物
    1. 生成导航栏
    2. 生成侧边栏
    3. 生成文章
    4. 生成页面
        1. 自定义页面
        2. 友情链接页面
        3. 搜索页
    5. 生成文章列表
    6. 网站地图
8. 编译静态索引
