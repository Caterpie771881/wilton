# wilton

为撰写技术博客设计的终端风格的静态站点生成器

访问量统计和评论区服务目前用的是腾讯的 EdgeOne, 后期会考虑加入更多平台的支持

目前 "Make it work" 阶段应该已经完成了, 开始慢慢对代码进行重构

> [!IMPORTANT]
> 当前代码比较混乱, 作者已经沉浸在自己的艺术中了, 每天起床第一件事就是大喊 "Coding 爽!"
>
> 大部分代码是作者手搓的, 但请不要相信作者的代码质量比 VibeCoder 更好
>
> 能跑起来, 但请慎用

## 构建流程

目前我对重构后的代码流程有如下设想:

* 初始化数据库与模型
* 接受用户输入
* 扫描博客文件夹 一边扫描一边构建数据库
* 读取配置文件
* 导入(依赖配置但)与博客内容无关的资产
  * css/js/fonts 主题文件
  * 图标
  * attachments 目录
  * 云函数
* 根据构建的数据库生成构建产物
  * 生成导航栏
  * 生成侧边栏
  * 编译并生成文章
  * 编译并生成页面
  * 生成文章列表
    * 所有
    * 分类
    * 标签
  * 网站地图
  * 编译静态索引

先按照这个流程写, 可能会有一些调整
